# 🎮 Juego: Piedra, Papel o Tijera (Interfaz Gráfica)

Proyecto de Python con interfaz gráfica de usuario (**GUI**) creada con **Tkinter** para jugar al clásico juego de **Piedra, Papel o Tijera** contra la computadora.

---

## 🎨 Características Visuales

- **Interfaz moderna y oscura**: Diseño limpio con paleta de colores estilo Dark Mode.
- **Tablero de Duelo**: Muestra los emojis gigantes de tu jugada y la de la computadora en tiempo real.
- **Marcador en tiempo real**: Registro de victorias del jugador, empates y victorias de la máquina.
- **Animación de suspenso**: Efecto de rueda/pensamiento en la computadora antes de revelar su decisión.
- **Botones interactivos**: Botones estilizados con efecto *hover* al pasar el cursor.
- **Gestión de partida**: Opciones para reiniciar el marcador o salir de la aplicación.

---

## 🚀 Cómo ejecutar el juego

1. Abre una terminal (o haz doble clic sobre el archivo si tienes Python asociado):
   ```bash
   python piedra_papel_tijera.py
   ```
2. Se abrirá la ventana gráfica del juego.
3. Haz clic en **🪨 Piedra**, **📄 Papel** o **✂️ Tijera** para jugar cada ronda.
